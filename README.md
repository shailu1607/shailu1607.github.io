## ✨ Overview

A clean, professional portfolio website built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies. Designed with a refined editorial aesthetic: dark sidebar, warm gold accents, and elegant typography using *Cormorant Garamond* and *DM Sans*.

## 📱 Responsive Design

- **Mobile-first hamburger menu** — slides in as a drawer with backdrop overlay
- Sidebar collapses at `768px`, full-width layout on small screens
- All grids and cards reflow to single column on mobile
- Touch-friendly tap targets throughout

## 🚀 Running Locally

No build step needed — just open in a browser.

```bash
git clone https://github.com/shailu1607/shailu1607.github.io.git
cd shailu1607.github.io
open index.html        # macOS
# or
start index.html       # Windows
```

Or serve with a local server to avoid any path issues:

```bash
npx serve .
# then open http://localhost:3000
```
